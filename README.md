# Картотека пациентов в городской поликлинике
## 1. Об приложении
Данное приложение создано в целях *хранении* и *обработки* медицинских карт пациентов.
## 2. Авторизация
Для того чтобы зайти в данное приложение необходимо авторизоваться, для этого в полях **логин** и **пароль** необходимо ввести user в оба поля.
